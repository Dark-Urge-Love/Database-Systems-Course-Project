暂时连不上数据库服务器

页面本身没问题，是 Windows 客户端没能连上 Ubuntu 服务器上的 MySQL。

错误信息

{{ message }}

按顺序检查这三步

  1. Ubuntu 是否在运行？
    打开开始菜单里的 Ubuntu 图标，能看到终端提示符就说明起来了。 本机 WSL 虚拟机在没人用时会自动关闭，这是正常的。
  2. MySQL 是否在运行？
    在 Ubuntu 终端里执行 dbstatus； 如果显示未运行，执行 dbup（或 sudo service mysql start）。
  3. 服务器地址对不对？
    在 Ubuntu 里执行 hostname -I 看当前 IP。 本程序会自动扫描并更新地址，稍等几秒刷新本页通常就能自动恢复。
