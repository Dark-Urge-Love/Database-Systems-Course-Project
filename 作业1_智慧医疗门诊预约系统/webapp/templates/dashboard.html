课程要求对应功能实现方式演示
基本 1创建数据表 药房采购工作台 第 1 步：CREATE TABLE drug_quote（供应商报价登记表） 去演示
基本 2插入数据 第 2 步：INSERT 录入 8 条报价 + INSERT…SELECT 新药批量上架 去演示
基本 3修改数据 第 3 步：UPDATE…JOIN 按报价调整目录内药品价格 去演示
基本 4删除数据 第 4 步：DELETE…LEFT JOIN 淘汰滞销药品（外键保护受引用数据） 去演示
基本 5删除数据表 第 5 步：DROP TABLE drug_quote 报价归档后销毁临时表 去演示
基本 6跨数据表操作 运营报表：医生开药金额 Top10（5 表 JOIN）、患者完整就诊流水（7 表 JOIN） 去演示
额外 1事务支持 患者挂号：SELECT…FOR UPDATE + INSERT + UPDATE 三语句同事务，失败整体回滚 去演示
额外 2索引支持 索引性能对比：同一查询走索引 / IGNORE INDEX 全表扫描，对比 EXPLAIN 与耗时 去演示
额外 3多用户并发 + 访问性能 挂号页「并发抢号」：10 线程同时抢一个号源，记录成功数/耗时；tools/concurrency_test.py 输出 TPS、P95 到 CSV 去演示
