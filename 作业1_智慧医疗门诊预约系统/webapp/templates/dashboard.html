课程要求 → 功能对照

课程要求对应功能实现方式演示
基本 1创建数据表 药房业务 →「业务档案」→ 新建业务档案：填写档案名称与需要记录的信息（如供应商名称、结算金额），系统据此建立数据表 去操作
基本 2插入数据 库房新到一种药 →「新药入库」填写名称/规格/厂家/单价/库存；或在业务档案里「录入记录」（如登记一家供应商） 去操作
基本 3修改数据 药品调价或库存盘点 → 药品目录点「编辑」修改单价、库存、在用状态，保存后立即生效 去操作
基本 4删除数据 录入错误的品种 → 药品目录点「删除」；已开过处方的药品会被拦下并提示改为停用（业务规则） 去操作
基本 5删除数据表 某类档案不再使用 → 在「业务档案」里删除该档案，其记录一并清理（核心业务档案受保护） 去操作
基本 6跨数据表操作 「运营报表」：医生开药金额排行（5 表关联）、患者完整就诊流水（7 表关联） 去操作
额外 1事务支持 患者挂号：SELECT…FOR UPDATE + INSERT + UPDATE 三语句同事务，失败整体回滚 去演示
额外 2索引支持 索引性能对比：同一查询走索引 / IGNORE INDEX 全表扫描，对比 EXPLAIN 与耗时 去演示
额外 3多用户并发 + 访问性能 挂号页「并发抢号」：10 线程同时抢一个号源，记录成功数/耗时；tools/concurrency_test.py 输出 TPS、P95 到 CSV 去演示
数据量≥5 表 / ≥10 万条 10 张表、22 万+ 条初始数据（见下方各表行数） 本页
数据关系多种数据关系 科室→医生→排班→预约（1-N）、预约↔就诊（1-1）、处方↔药品（N-M 经明细表） 见设计文档
